
# Custom Animation Engine

This project is a custom animation engine created from scratch using **C++** and **OpenGL**, designed to explore and implement the techniques involved in modern game character animation. The project covers both foundational and advanced animation concepts, showcasing the mechanics behind character animation systems.

---

## Features

- **Data Loading**: 
  - Integrated support for loading data from **glTF files**.
- **Advanced Animation Techniques**:
  - Implemented **fading** and **crossfading** for smooth transitions between animations.
  - Added support for **additive blending** to combine animations dynamically.
- **Inverse Kinematics**:
  - Developed IK solutions using **CCD** (Cyclic Coordinate Descent) and **FABRIK** (Forward and Backward Reaching Inverse Kinematics) algorithms.
- **Graphics Integration**:
  - Utilized **OpenGL** for rendering and visualization.

---


## Key Learning Objectives

- Building a robust animation system from scratch.
- Gaining in-depth knowledge of **glTF file parsing** and its integration into an animation pipeline.
- Implementing **smooth blending techniques** for realistic transitions between animations.
- Exploring **Inverse Kinematics (IK)** for character pose manipulation.
